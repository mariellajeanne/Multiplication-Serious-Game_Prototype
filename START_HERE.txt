PANADERYA QUEST — QUICK START (WINDOWS)
======================================
1. Extract the downloaded ZIP.
2. Open VS Code → File → Open Folder → select the WHOLE extracted folder.
3. Press Ctrl+Shift+X; install "Live Server" by Ritwick Dey.
4. Open index.html. Right-click → "Open with Live Server".
5. The game should open at http://127.0.0.1:5500/ (port may vary).
6. Save an edited file (Ctrl+S) and Live Server will refresh.

EDIT WITH CODEX USING YOUR CHATGPT ACCOUNT:
1. In VS Code Extensions, install "Codex" (publisher OpenAI).
2. Open the Codex sidebar and select "Sign in with ChatGPT".
3. Open the whole project folder. NO NEED to open the correct source file first.
4. Tell Codex your desired change in plain English. It can find and edit files.
5. Have it read AGENTS.md and worksheet/README.md to preserve game behavior.
6. Review changes / test in the browser; use Git to keep versions.
