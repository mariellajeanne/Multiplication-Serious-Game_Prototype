# Panaderya Quest — Bakery Long Multiplication Game

An interactive Filipino bakery-themed long multiplication prototype.

## Play

Open the GitHub Pages site for this repository, or open `index.html` locally in a modern browser.

## Features

- v33-inspired interactive worksheet with carry operations, guidance arrows, and sound effects
- Filipino bakery food menu and rarity-based order tickets
- Coin rewards, randomized chests, menu upgrades, fusion, kitchenware, decorations, and unlockable modes
- Tablet-friendly self-contained HTML prototype

## GitHub Pages deployment

Use **Settings → Pages → Deploy from a branch → main → /(root)**. The `index.html` file is the site's entry point.

## Notes

Game progress is saved in the browser and is specific to the site/domain. This is a development prototype; numbers, reward odds, and mastery progression are subject to balancing.
