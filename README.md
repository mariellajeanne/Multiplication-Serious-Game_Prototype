# Batch & Carry — v35 Packing Hall + authentic v33 worksheet

## Play locally
Open `index.html` in Chrome or Edge. The file is self-contained; no build or internet required.

## Publish/update on GitHub Pages
Upload `index.html` **to the root** of the existing GitHub repository, replacing the older `index.html`. Commit changes to `main`. Leave GitHub Pages publishing from `main / (root)`; the URL remains unchanged.

## What was preserved
The embedded worksheet comes from the exact user-uploaded `BatchCarry_v33_BakeryReceipt.html` source. Its calculation logic was not rewritten:

- Connect the correct top and bottom digit, via tap or pointer drag.
- Tap the floating multiplication expression to reveal product digits.
- Place separate ones and tens tiles via click/tap or drag into the appropriate positions.
- Put a provisional tens tile in the partial-product row and swipe/drag it up into the next carry, or place it directly in the carry shelf.
- Drag the old carry onto the newly placed/floating product's ones digit, or select its source and destination.
- Allow either carry-handling order permitted by v33's state machine.
- On two-row problems, swipe down to trigger the original animated partial-product addition.
- Preserve v33's existing sound effects, receipt styling, and Undo/Reset behavior.

A small bridge was appended **after** the v33 interaction definitions: it receives order tickets from the outer Packing Hall, reports UI progress, and signals completion to award an Auto-Packer. No v33 interaction function was replaced with v3/v34 behavior.

## Scope / educational caveat
The v33 multiplication engine supports `1–99999 × 1–99`. The outer ticket generator is deliberately constrained to at most 5-digit-by-2-digit contracts. This means the full 25-star tier scale is not yet available, although all ticket-grade visuals/definitions remain in the shell.

In v33, product values are generated by tapping the multiplication expression and final addition runs as a swipe-triggered animation. It does **not** require the multiplication-table lookup or manual column addition from other prototypes. Those differences are intentional to preserve the requested v33 behavior.

The game uses a separate browser save-data key from earlier versions, so older versions' saved progress does not automatically carry over.
